# Romil Patel — Cybersecurity Portfolio

An evidence-first, responsive portfolio for cybersecurity research, DFIR, threat hunting, and authorized offensive security.

## Run locally

```powershell
node server.mjs
```

Then open `http://127.0.0.1:4173`.

The site has no package dependencies and can also be deployed directly to GitHub Pages, Netlify, Cloudflare Pages, or any static host.

## Content scope

- Two featured projects only: PHANTOM DFIR and BountyForge Toolkit
- LinkedIn-derived experience, education, volunteering, community work, technical stack, and all 20 listed credentials
- GitHub-verified project details and repository links
- Original generated hero art with deterministic HTML/CSS typography and claims

## Files

- `index.html` — semantic site content
- `styles.css` — visual system and responsive layouts
- `script.js` — motion, counters, navigation, command palette, and signal canvas
- `server.mjs` — zero-dependency local static server
- `assets/` — local imagery and creative provenance
